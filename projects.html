NanoOCR - Optical Character Recognition Model

  • Developed NanoOCR, a lightweight Optical Character Recognition (OCR) system trained from scratch on ~45,500 character images across 36 alphanumeric classes, achieving 97.46% validation accuracy.
  • Designed a compact CNN architecture with Batch Normalization, ReLU, MaxPooling, Dropout, and a fully connected classification head, reducing the model to just 626K parameters (~2.4 MB)./li>
  • Optimized model training using AdamW and Cross-Entropy Loss, achieving 97.22% training accuracy in ~45 seconds over 5 epochs on a single T4 GPU.
  • Built an end-to-end image processing pipeline using OpenCV for Gaussian denoising, adaptive thresholding, contour-based character segmentation, and left-to-right bounding-box sorting.
  • Deployed the OCR model as a web application using FastAPI, ONNX CPU inference, JavaScript, HTML, and Tailwind CSS, enabling near-real-time character recognition with a lightweight inference footprint.
